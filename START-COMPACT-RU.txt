Clips Kitty — компактная модифицированная версия для Windows / NVIDIA

1. Полностью распакуйте ZIP в отдельную папку.
2. Для загрузки распознавания речи запустите Download-Models.cmd.
   Для RTX 3050 выбирайте 2 (large-v3-turbo); 3 скачает также модель для CPU.
   Нужен интернет: примерно 1,6 ГБ для GPU или 2,1 ГБ для обеих моделей.
3. Запустите Clips Kitty.exe. Языковую модель Ollama (Gemma, Qwen и т. п.)
   выберите в мастере настройки / Models. Она скачивается отдельно, как и раньше.
4. Наши функции находятся в разделе «Шаблоны монтажа».

Python устанавливать не нужно: загрузчик использует встроенный Python приложения.
Без загрузки Whisper доступны интерфейс, редактор и монтаж уже готовых клипов.
Если модель речи ещё не загружена, первая обработка видео также может скачать
её автоматически; Download-Models.cmd позволяет сделать это заранее.

Сохранены FFmpeg/NVENC, CUDA 13 для PyTorch и Ollama, CUDA 12 для Whisper,
CPU и Vulkan Ollama, YOLO, TalkNet и остальные вспомогательные модели.
Убраны только веса Whisper, четыре повторные DLL cuBLAS и альтернативный
CUDA 12 runner Ollama. Для ускорения Ollama через CUDA 13 нужен совместимый
драйвер NVIDIA; при его недоступности остаются CPU/Vulkan.

Архив — полноценный ZIP, подходящий для обычной распаковки Windows.
Запускайте приложение после распаковки, не из окна просмотра ZIP.
